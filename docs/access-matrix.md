## Rules

- ER: employee-level ER data is ER_RESTRICTED only (ASSUMPTION A-10, needs ER leadership decision). Aggregate ER indicators are available to HR Analytics Admin, HR Leadership and ER_RESTRICTED only; small-cell suppression is PENDING.
- Exports: employee-level exports are HR Analytics Admin only. Aggregate exports come from a published snapshot, are scoped, and are audited. Read-only Leadership and ER_RESTRICTED have no export.
- Division/Department Heads see published aggregates for their own scope only; no employee-level drill-down (ASSUMPTION A-09).
- System Admin has no business-data permission (proved by test).
- Dashboards show published data only, never work-in-progress (Phase 2 enforcement point).
- Identity: Microsoft Entra ID SSO + MFA is the target; Phase 1 uses a mock provider that refuses to run in production.
